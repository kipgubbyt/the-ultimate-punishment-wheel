# Random Image Roll

A static, dependency-free image randomizer containing the images from the supplied ZIP.

## Deploy

**Cloudflare Pages**
1. Create a Pages project.
2. Upload this ZIP using the direct-upload flow, or connect a Git repository containing these files.
3. Use the project root as the build output directory. No build command is needed.

**GitHub Pages**
1. Extract this ZIP into the root of a repository.
2. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`.
3. Save and wait for deployment.

The site uses only local image files and works without a server-side runtime.
